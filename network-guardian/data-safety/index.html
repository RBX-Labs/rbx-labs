Data Safety

This page summarizes the data practices that should be reflected in Network Guardian's Google Play Data Safety form. The Play Console declaration remains the authoritative store disclosure.

Sharing and security

  • Google receives information needed to authenticate the account.
  • Google Cloud hosts the Network Guardian API and database.
  • Network data may contribute to aggregate reputation signals; guest scans are not uploaded as community contributions.
  • Data is transmitted over HTTPS.
  • The app currently does not use advertising SDKs.

User controls

Users can scan as a guest, deny optional permissions, sign out, and request account deletion. See the Privacy Policy, Permission disclosures, and Account deletion pages.
