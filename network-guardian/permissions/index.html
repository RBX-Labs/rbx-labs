Android permission disclosures

Why Network Guardian requests access

Network Guardian requests only the access needed to inspect the network you are using, run optional background checks, and explain the results.

Last reviewed: August 6, 2026

Nearby Wi-Fi and network state

Used to identify the connected Wi-Fi network, inspect nearby network signals where Android permits it, and determine whether the device is online. This powers the scan and trust result.

Location

Android may require location access for Wi-Fi identifiers. Network Guardian uses location only when allowed to associate a scan with an approximate area and improve network reputation context. You can deny location, though some Wi-Fi details may be unavailable.

Notifications

Used to show Background Mode status and important service interruptions. Notifications are not used for advertising.

Foreground service

Used only when you enable Background Mode, so Android can keep scheduled network checks visible and stoppable. Background Mode is not required for one-time local scans.

Your control

You can grant, deny, or revoke permissions from Android Settings. If a permission is denied, the app should continue to provide the portions of the scan that do not require it and explain what could not be measured.
