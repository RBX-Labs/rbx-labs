# Website IA Icon Pack

This pack extends the core NG icon family for website information architecture sections.

## Icons

- `ng_web_audience.svg`: audience segments (travelers, teams, SMBs)
- `ng_web_sector.svg`: sector / institutions
- `ng_web_pricing.svg`: pricing / plans
- `ng_web_api.svg`: API / developer integration
- `ng_web_telemetry.svg`: telemetry stream
- `ng_web_trust_graph.svg`: trust graph / network relationship
- `ng_web_policy.svg`: policy / governance
- `ng_web_risk_trend.svg`: risk trend / threat movement
- `ng_web_partner_stack.svg`: partner stack / platform layers
- `ng_web_compliance.svg`: compliance / controls

## Suggested Mapping

- Hero/Telemetry accents: `ng_web_telemetry`, `ng_web_trust_graph`
- Leaderboard side cards: `ng_web_risk_trend`, `ng_web_telemetry`
- Capability stack: `ng_web_audience`, `ng_web_partner_stack`, `ng_web_api`
- Trust/Who it serves: `ng_web_sector`, `ng_web_policy`, `ng_web_compliance`
- Business model: `ng_web_pricing`, `ng_web_api`, `ng_web_compliance`
