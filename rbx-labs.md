# RBX Labs Brand Notes

Use this as the source-of-truth note for the RBX Labs logo and wordmark treatment used in event posters and similar hero graphics.

## Logo Asset

- File: `/Users/bangabot/Downloads/rbx-light copy.png`
- Format: PNG
- Background: transparent / cutout
- Mark style: multicolor RBX monogram with cyan, blue, and purple gradients
- Do not redraw or substitute with a generic icon. Use the supplied asset directly.

## Brand Row Pattern

This is the preferred treatment for poster-style layouts:

- Place the logo and the `RBX Labs` wordmark together as one row
- Position the row below the main heading and subheading
- Keep the row centered within the left content column
- Keep the row visually separated from the body content below

## Recommended Specs

These are the values used in the latest landscape poster composition.

- Canvas reference: `1536 x 1024`
- Logo display size: `84 x 84 px`
- Wordmark text: `RBX Labs`
- Wordmark font: `Arial Bold`
- Wordmark size: `54 px`
- Wordmark color: off-white, approximately `#EEF1F7`
- Gap between logo and wordmark: `20 px`
- Brand row alignment: left-to-right, horizontally centered as a group
- Brand row vertical position: around `y = 362 px` on the 1536 x 1024 layout

## Heading and Subheading Relationship

- Main title stays above the brand row
- Subheading should be a single line when space allows
- Keep the brand row below the subheading, not overlapping it
- The brand row should feel like a signature line, not a separate badge

## List-Line Treatment

Use a short supporting line when needed:

- `Real-world trust signals • Evaluation • Human Oversight`

Recommended styling:

- Font: `Arial`
- Size: `24 px`
- Color: light gray-blue, approximately `#DCE4F0`
- Centered under the brand row

## Layout Notes

- Keep the right-side content narrower in landscape so the lower icon row remains visible
- Crop the poster image rather than scaling it down when reducing width
- Avoid floating the logo at the extreme corner
- Avoid recreating the logo with text or vector approximation
